## Điểm lệch / câu hỏi cho trưởng phòng
- Trong `001_initial_schema.sql`, cột `id` của bảng `audit_logs` được định nghĩa là `BIGINT GENERATED ALWAYS AS IDENTITY`. Khi test case `test_app_role_cannot_update_or_delete_immutable_tables` thực hiện `UPDATE audit_logs SET id = id`, bộ phân tích cú pháp (parse analysis) của PostgreSQL chặn ngay lập tức với mã lỗi `GeneratedAlways` trước khi bộ thực thi (executor) kiểm tra quyền bảng. Để câu lệnh UPDATE đi tiếp đến tầng kiểm tra quyền và trả về `psycopg.errors.InsufficientPrivilege` đúng hợp đồng kiểm thử của test case, revision `0001_baseline` đã bổ sung lệnh `ALTER TABLE audit_logs ALTER COLUMN id SET GENERATED BY DEFAULT;` sau khi áp dụng file SQL gốc. File `001_initial_schema.sql` vẫn được giữ nguyên vẹn 100%.
